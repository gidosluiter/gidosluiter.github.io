# Website van Gido — Havo 4B

Een eenvoudige informaticawebsite met HTML en CSS. Er is geen installatie of buildstap nodig.

- `index.html`: over mij en mijn hobby’s.
- `invoer.html`: invoer, verwerking en uitvoer.
- `binair.html`: bits, bytes en Binary Bonanza.
- `kleurmodellen.html`: RGB, CMYK en kleurcodes.
- `compressie.html`: bitmap, vector en compressie.
- `ai.html`: AI-gebruik en Gemini op mijn Google Pixel.
- `stylesheet.css`: de opmaak, met Nederlandse comments.
- `assets/`: de afbeeldingen.

Op elke pagina staan een afbeelding, uitleg en een YouTube-video met een reden voor de keuze. De video's moeten voor het inleveren nog zelf worden bekeken.

Start lokaal vanuit deze map met `python3 -m http.server 8000 --bind 127.0.0.1`.

GitHub Pages publiceert vanuit `main` en `/(root)` op https://gidosluiter.github.io/.

De oorspronkelijke spel- en oefenbestanden zijn bewaard. Ze horen niet bij het hoofdmenu van deze opdracht.
